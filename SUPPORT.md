# Support

| Need | Channel |
| --- | --- |
| Architecture or implementation question | [GitHub Discussions](https://github.com/davidahmann/production-agent-engineering/discussions) |
| Reproducible repository defect | [Bug report](https://github.com/davidahmann/production-agent-engineering/issues/new?template=bug.yml) |
| Control, pattern, or blueprint proposal | [Design proposal](https://github.com/davidahmann/production-agent-engineering/issues/new?template=design-proposal.yml) |
| Incorrect or stale evidence | [Evidence correction](https://github.com/davidahmann/production-agent-engineering/issues/new?template=evidence-correction.yml) |
| Vulnerability | [Private security report](https://github.com/davidahmann/production-agent-engineering/security/advisories/new) |

Support is community-based and best effort. Include the artifact path, control IDs, runtime assumptions, and validation output needed to reproduce the question.
