## [1.1.0] - 2026-08-08

- Add a compact, end-to-end shipment-risk FDE walkthrough with a hybrid ML, deterministic-policy, foundation-model explanation, and human-review reference; include explicit value, adoption, service-review, threat, evaluation, and executable routing artifacts.
- Add the complete Beyond Twelve-Factor workload crosswalk and link it to the FDE delivery and operating model.
- Reposition the project as The FDE Guide: value engineering and production architecture for AI-enabled systems.
- Add a value-engineering and frugal-architecture guide, software-architecture and intelligence-selection guide, hybrid-intelligence blueprint, and selection record.
- Expand delivery guidance from agent-only design to explicit rules, optimization, ML, retrieval, foundation-model, agent, and human-review choices.
- Rework the README around plain-language user journeys, expected outputs, and a guided reference-system tour.
- Expand `AGENTS.md` into a task-routed repository map and align the compact `llms.txt` index.
- Validate repository-local links in `llms.txt` to prevent agent-navigation drift.
- Align local and pull-request validation with lifecycle scripts disabled during dependency installation.
- Reject artifact, schema, documentation, and system references that resolve outside the repository; validate trace-contract dependencies and governed-artifact coverage.
- Bind governed JSON files to their expected local schemas, allowlist URI schemes, validate agent dependency types, and add integrated bypass regressions.
- Validate reference-style documentation links, bind evaluation suites to their owning design, and enforce telemetry-versus-incident operation roles.
- Add an outcome-led FDE lifecycle covering field discovery, value, solution delivery, adoption, customer handoff, post-production operation, and retirement.
- Add a machine-readable workflow charter with a schema, template, reference example, dependency validation, and contract tests.
- Add machine-readable evaluation-report and solution-release contracts with governed reference validation and negative tests.
- Add governed capability-provenance and authority-attenuating handoff contracts with fail-closed semantic regressions.
- Extend tool contracts with bounded data-exposure and capability-aware network policies, including semantic scope checks.
- Enforce declared invoice and policy read scopes before disclosure, bind returned policy data to the authorized tenant, and cover both denials with executable regressions.
- Refresh trusted caller authority at every boundary, bind stage and commit requests to admitted policy decisions, and bind effect receipts to the complete declared reference release.
- Bind effect receipts and readback evidence to signed service attestations, canonical subjects, actor identity, and release context.
- Derive write idempotency from a stable business-operation identity, keep source revisions as preconditions, and execute a revision-drift retry regression.
- Admit the executable reference only under its exact solution-release digest, bind five tool capabilities and the runtime artifact graph, and reject release drift before data access or effects.
- Add a typed readback capability, effect-unknown reconciliation, pinned receipt issuers and keys, and runtime step, time, and cost enforcement.
- Replace workflow-specific trace details with hashed source, decision, artifact, effect, receipt, and error references under Trace-event Schema 1.2.
- Bind evaluation claims to measured runner output and an explicit host-process environment without implying unavailable sandbox isolation.
- Make delegated handoff consumption recipient-bound, replay-safe, and atomically budgeted across workers and restarts.
- Document the Tool Contract 1.1 migration and keep prior-release rollback guidance explicit.
- Add enterprise-platform, data-analysis, and controlled-improvement blueprints, change-management and behavior-monitoring standards, and a maintainer runbook.
- Expand the control and pattern catalogs for value, delivery, adoption, evaluation claims, capability-aware egress, compatible releases, and production learning loops.
- Add dated OpenAI, Anthropic, Palantir, and practitioner evidence plus a chapter-level production-agent video index.
- Add folder-level maps for templates, schemas, and production operations.
